# Following Saharan dust

An interactive Visual Perception project proposal on detecting, measuring and tracking Saharan dust plumes in satellite imagery.

## Present the deck

Open `docs/index.html` in a browser. The images and simulations are bundled, so you can present offline. Use **← / →** to move through slides and reveals, **N** to toggle notes, and **F** for fullscreen. The section bar jumps to the start of a section.

The opening images are observations from NASA Earth Observatory. The segmentation and tracking demonstrations use synthetic data to illustrate the proposed method.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/docs**. GitHub Pages on a private repository requires an eligible GitHub plan.
